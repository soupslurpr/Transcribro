# Dependency notices

The app packages two generated package-level notice files for its
shipped declared dependencies (the per-dependency records the
third-party-attribution skill requires for shipped dependencies; CREDITS
points at them from its "Packaged combined notices" section):

- `speech/src/main/assets/licenses/Rust-Dependency-NOTICES.txt` — the
  crates compiled into `libtranscribro.so`, with their declared license
  expressions and the verbatim license texts from their published
  packages.
- `app/src/main/assets/licenses/Android-Dependency-NOTICES.txt` — the
  modules packaged from the release runtime classpath, grouped by the
  license declared in each module's POM (parent POMs followed where a
  module declares none), pointing at the packaged full license texts.

Both are generated by `tools/src/bin/gen-dependency-notices.rs` from
the lockfiles. Do not edit them by hand; regenerate them whenever
`engine/Cargo.lock` or the Gradle dependencies change:

```sh
export PATH="$HOME/.cargo/bin:$PATH"

# License gathering for the engine graph (config: engine/about.toml;
# cargo-about 0.9.3).
cargo about generate --format json --locked \
    --manifest-path engine/Cargo.toml > /tmp/about.json

# The engine dependency graph itself.
cargo metadata --format-version 1 --locked \
    --manifest-path engine/Cargo.toml > /tmp/metadata.json

# The app release runtime classpath components.
./gradlew -I tools/notices/dep-inventory.init.gradle \
    :app:printReleaseRuntimeDeps --console=plain -q \
    | grep "^COMPONENT " > /tmp/gradle-components.txt

# jni 0.22.4 is the one shipped crate whose published package omits
# its license files; take them from its repository at the release tag
# (Cargo.toml declares the same "MIT OR Apache-2.0").
mkdir -p /tmp/jni-licenses
curl -sL https://raw.githubusercontent.com/jni-rs/jni-rs/v0.22.4/LICENSE-MIT \
    -o /tmp/jni-licenses/LICENSE-MIT
curl -sL https://raw.githubusercontent.com/jni-rs/jni-rs/v0.22.4/LICENSE-APACHE \
    -o /tmp/jni-licenses/LICENSE-APACHE

cargo run --release --locked --manifest-path tools/Cargo.toml \
    --bin gen-dependency-notices -- \
    --metadata /tmp/metadata.json \
    --about-json /tmp/about.json \
    --registry-src ~/.cargo/registry/src \
    --license-fallback jni=/tmp/jni-licenses \
    --gradle-components /tmp/gradle-components.txt \
    --gradle-cache ~/.gradle/caches/modules-2/files-2.1 \
    --out-rust speech/src/main/assets/licenses/Rust-Dependency-NOTICES.txt \
    --out-android app/src/main/assets/licenses/Android-Dependency-NOTICES.txt
```

The generator fails loudly on anything it cannot settle (a crate with
no license files and no fallback, a metadata/cargo-about license
mismatch, a packaged module whose POM chain declares no license, an
unrecognized license or cfg atom) rather than improvising a record.
